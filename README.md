Railway reservation system

System for booking the trains, searching them and cancelling the tickets:

Features: 
1. View the available trains: User is able to view the available trains and seats, cost, destination
2. Book ticket: User is able to book train tickert
3. Cancel ticket: When the user won't go for the ticket, he may cancel it and seats will increase for other users who needs to use the ticket to book 
4. Finally user can search the trains, by destination so far
5. Exit the system, if you didn't find the feature you're looking for not there yet, or if you are done with what you wanted to do, either to book, to cancel or to search for trains
